## Direction contract

THESIS: The page shows an owned app being assembled by an agent while the rented bill collapses beside it. It refuses the category default of a typed prompt box over a row of equal feature cards.

OWN-WORLD: Near-black navy ground lit from above by one green light source; hairline borders at 10% white; a glass navigation bar; windows and cards with a lit top edge; Funnel Display set upright, large and tight; green reserved for what is owned, a muted red only for rented prices; abstract line illustrations that move like instruments, never stock icons.

STORY: The visitor names a tool they rent, sees it rebuilt as an app they own, sees the yearly bill fall to $348, learns FrogBot can build it for them in 2 weeks, and books a build call.

FIRST VIEWPORT: Glass header with logo, links and Book a build call.
