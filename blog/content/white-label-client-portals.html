Why per-seat portal tools break agency economics

When an agency builds a client portal on Retool, Airtable, or a SaaS portal builder, the client inevitably asks to invite 40 stakeholders. Suddenly the software bill jumps by $600–$1,500/month—eating straight into your monthly retainer or forcing an awkward upsell conversation.

With FrogBot and Dojo, client seats cost $0. You can charge a client a $500/month hosting and maintenance retainer while your underlying Dojo cost is fixed at $29 or $79/month.

Step 1: Tenant-isolated row-level access control

Every collection in FrogBot supports declarative access control functions that filter queries automatically at the database layer:

export const Deliverables: CollectionConfig = {
  slug: 'deliverables',
  access: {
    read: ({ req }) => {
      if (req.user?.role === 'agency-admin') return true;
      return { clientOrg: { equals: req.user?.clientOrg } };
    },
  },
  fields: [
    { name: 'title', type: 'text', required: true },
    { name: 'clientOrg', type: 'text', required: true, index: true },
    { name: 'status', type: 'select', options: ['Draft', 'Needs Client Approval', 'Approved'] },
  ],
};

Step 2: White-label the Admin UI in 3 lines

Swap in your client's brand mark, favicon, and custom domain in frogbot.config.ts:

admin: {
  meta: {
    titleSuffix: '— Acme Client Portal',
    appIcon: '/acme-logo.svg',
  },
}

Step 3: Isolate client projects and hand off cleanly

On the Dojo Business plan ($79/app/mo), you can place each client's apps inside their own Project with an isolated access list so client stakeholders only ever see their own environment. And if a client ever buys out the project to run in-house, you can transfer the Dojo project to their organization—or hand them a standard git clone + pg_dump with $0 transfer fees.
