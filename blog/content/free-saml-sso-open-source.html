Ending the "SSO Tax"

For the last decade, SaaS pricing pages have followed the same playbook: offer a $20/seat starter tier, then require an upgrade to a $65–$175/seat "Enterprise" plan the moment your IT team asks for Okta or Google Workspace SAML login.

Charging 3x more per user just to verify a signed XML or OIDC token is the exact kind of rent-seeking we built FrogBot to kill.

What ships free in the MIT core

Every FrogBot application includes full authentication and authorization in the open-source framework:

  • SAML 2.0 & OIDC strategies: Connect Okta, Microsoft Entra ID, Google Workspace, OneLogin, or any standard identity provider.
  • Row- and field-level RBAC: Write TypeScript access functions that filter rows by user role, department, or client tenant—enforced automatically in both REST and Local API calls.
  • Scoped API keys: Generate hashed bearer tokens for scripts, CI pipelines, and MCP clients.
