Key takeaways

  • Time required: ~45 minutes from CSV export to live production URL.
  • Annual savings: $13,152/year (25 Airtable Business seats at $13,500/yr → $348/yr on Dojo Pro).
  • What you upgrade: 50,000-row record limits become real Postgres tables; $45/seat editor fees become $0/seat; fragile automations become typed background jobs and AI agents.

Step 1: Scaffold your FrogBot app and install the agent skill

Open your terminal and create a new FrogBot project, or paste the install prompt directly into Claude Code, Cursor, or OpenCode:

npx create-frogbot-app ops-base
cd ops-base

Your project comes pre-configured with the FrogBot coding-agent skill in skills/frogbot/SKILL.md.

Step 2: Drop in your Airtable CSV export

Export your primary Airtable tables (Inventory.csv, Suppliers.csv, Orders.csv) into the project folder and prompt your coding agent:

"Read Inventory.csv and Suppliers.csv. Create FrogBot collections for both with relationships, a Kanban board view grouped by status, a Calendar view by deliveryDate, and a seed script that imports the CSV rows."

Your agent will generate a clean frogbot.config.ts with table, Kanban board, and Calendar views built in—no custom frontend code required.

Step 3: Add an AI categorization agent and Slack notifications

Want AI to categorize incoming rows or alert #ops in Slack when stock runs low? Add @frogbotai/piece-slack and a 10-line agent config:

const inventoryAgent: AgentConfig = {
  slug: 'inventory-triage',
  model: 'anthropic/claude-sonnet-4-5',
  instructions: 'Categorize imported supplier SKUs and flag items below reorder threshold.',
};

Step 4: Deploy code and data in one command

Push your local app and imported Postgres data to Dojo with a single CLI command:

npx frogbot share --data

Invite all 25 teammates (or 250) with full editor permissions and SAML SSO—your bill stays $29/month flat.
